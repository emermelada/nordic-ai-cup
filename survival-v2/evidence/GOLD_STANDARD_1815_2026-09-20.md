## 6. Why the gold run cannot be replayed bit-exactly (honest limitation)

The grader's simulator seed is neither recorded in the payload nor visible in the trace, and it is not
the same between attempts: the second attempt (queued 08:11Z) produced population 37 at t=130 s on the
same controller, while the gold run had 12 at t=130 s. A local replay therefore cannot be matched by
searching small seed ranges — verified empirically: 400 candidate seeds (1..400) replayed with hive
exactly as deployed (hive seed 0, same SimulationCore config) reproduce the gold's population curve in
0 of 400 cases (experiments/seed_id.py).

Consequence for the forensics: the gold run's per-agent energy, genome and birth/death detail cannot be
recovered for THAT run. What can be compared is everything the trace carries (population, score,
latency over time) against local runs, plus the mechanistic reasoning from the controller's own
parameters. The local distribution study (Phase 1/2, experiments/traj_map.py + analyze_phase12.py)
supplies the per-agent detail for the same controller under the same simulator.

## 7. Interference caveat that must travel with this artifact

The gold run's first ~139 s were served while a stray test client of mine was also posting to the same
hive process (see the client counters in server_log.jsonl: 127.0.0.1 stops at 6,008 while 46.62.240.126
continues). hive resets its internal state whenever sim_time goes backwards, so the gold run's early
trajectory was perturbed repeatedly. The clean, monotonic 16,170-row run starts exactly when that client
stopped. Treat t < 140 s of the gold run as contaminated; the 1815.55 itself is not in question (16,170
consecutive requests, 0 errors, single monotonic sim_time).

## 8. Where the 1815 came from (arithmetic, no interpretation)

    score = 0.1 * ticks + fruit_energy/1000 - eaten_energy/100
           = 1755.6 (tick term) + ~59.9 (fruit term) = 1815.5   -> 96.7% of the score is survival time.

The tick term is capped by the game rule `sim_time <= 3000`, so the ceiling is ~3000 + fruit for a run
that reaches the cap.
