## 3. The V2 mechanism: genome-aware breeder selection (implemented this session)
Design (PIVOT_V2 §4) said "the genome of every agent is in the observation". **That is FALSE as
stated**: an observed Agent carries only `{'type','distance','angle','rel_dir','id'}`
(creature.py:170-175, `include_id=True`) — no traits. So the plan as written was not implementable.
**The fix that makes it implementable:** the request carries the agent's OWN six traits
(DTOs.py:14-20: speed, sprint_speed, hearing_radius, vision_angle, vision_range, max_energy), and
every observation carries the conspecific's `id`, so an id→traits table maintained from our own calls
reconstructs the whole fleet's genotype with **no new input channel**. That table is what ranks
breeders.

Implementation (all in `best_controller.py`, `genome_select 0.0` = OFF):
* `_TRAITS` id→[vision, cone, hearing, max_energy, speed, sprint, last_epoch], TTL-pruned like `_GC`.
* `U = Σ w_i · trait_i/cap_i` (caps 400 / π/2 / 100 / 1000 / 20 / 40 — the sim's own 2x caps).
* a spawn is admitted only if the parent's rank in the living fleet ≤ `gs_topk` (default 2), with
  `gs_rescue_pop` (1) and `gs_min_known` (3) escapes so the age-relay can never be broken.
* `gs_phase_tick`/`gs_late_energy_mult`: after production has halved 4x the objective shifts from
  perception to the BANK (max_energy is what lets a survivor outlast a decayed world).
* cost: **zero energy** — it only decides who may spend the 100-energy spawn.

* **The mechanism gate PASSES**: selection moves the genome (fleet mean vision 201.8 → 236.6, late-episode
  262.8, newborns 199.7 → 237.3 against a 400 cap), where the deployed controller's vision had been
  FLAT at ~200 through 119 births. So the "genotype-blindness" gap in PIVOT_V2 §4 is now closed by
  measurement, not by argument.

* **The win is NOT a thrift win** — the opposite: population HALVED (12.1 → 6.5) and fruit income fell

  gains ticks, because the surviving agents see ~2x the area. This is the first arm in the project
  with that profile.

### Population-collapse / bankruptcy lever (the DEEPER read of the same numbers)
Selection halved the fleet without costing survival — which finally gives an *earned* answer to the
question "what fleet size?" that the thin-relay arms kept getting wrong: they shrank the fleet by
CONSTRAINING behaviour (and lost income); selection shrinks it as a *consequence* of better agents.
Whether the optimum is even smaller is now testable on a fleet whose genomes are no longer default.
